---

## 🖼️ Sobre el Proyecto

Este proyecto nace de la necesidad de crear una identidad digital para una marca de decoración. El objetivo fue desarrollar una **Landing Page** moderna, estética y funcional que permitiera a los usuarios explorar categorías de productos y contactar con la marca.

El foco principal del desarrollo estuvo en el **Diseño Responsivo (Mobile First)** y en el uso de **Vanilla JavaScript** para manejar la interactividad del usuario sin depender de librerías externas.

## ✨ Características Principales

* **🎨 Diseño UI/UX Moderno:** Uso de una paleta de colores coherente con la identidad de marca (tonos tierra/neutros/etc.) y tipografías legibles.
* **📱 Totalmente Responsivo:** Se adapta perfectamente a celulares, tablets y escritorios usando **Media Queries**.
* **🛍️ Catálogo Interactivo:**
    * Uso de **CSS Grid** para la disposición de productos.
    * Efectos de **Hover** y transiciones suaves en CSS.

---

## 🛠️ Tecnologías Utilizadas

### Maquetación (HTML5)
* Uso de etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) para mejorar el SEO y la accesibilidad.

### Estilos (CSS3)
* **Flexbox** para alineaciones y barras de navegación.
* **CSS Grid** para la galería de productos.
* **Variables CSS (:root)** para mantener la consistencia en colores y fuentes.
* **Animaciones** sutiles (`transform`, `transition`) para mejorar la experiencia de usuario.

### Funcionalidad (JavaScript)
* Manipulación del **DOM** para eventos de click y scroll.
* **Event Listeners** para el menú desplegable y botones de acción.
